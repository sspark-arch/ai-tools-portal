# ArtistAI - 아티스트를 위한 AI 도구 포털

아티스트들이 너무 많은 AI 모델 중에서 자신에게 맞는 도구를 선택하기 어려운 문제를 해결하기 위한 AI 도구 포털입니다.

## 특징

- 🎨 **음악/오디오**: Suno, AIVA, iZotope, ElevenLabs 등 음악 생성 및 편집 도구
- 🎬 **이미지/비디오**: Midjourney, Runway, D-ID, Synthesia 등 시각 콘텐츠 생성 도구
- ✍️ **텍스트/작성**: ChatGPT, Claude, Copy.ai, Jasper 등 텍스트 생성 도구
- 🔍 **스마트 필터링**: 카테고리, 가격, 검색 기능으로 원하는 도구 찾기
- ⇄ **도구 비교**: 최대 4개의 도구를 한번에 비교

## 기술 스택

- HTML5
- CSS3 (Flexbox, Grid, 반응형 디자인)
- Vanilla JavaScript

## 시작하기

1. 파일을 다운로드하거나 클론합니다
2. `index.html`을 브라우저에서 엽니다
3. 다양한 AI 도구를 탐색하고 비교합니다

## 배포

이 프로젝트는 Netlify에 자동 배포됩니다:
- GitHub 저장소와 연동
- `main` 브랜치에 푸시하면 자동으로 배포됨
